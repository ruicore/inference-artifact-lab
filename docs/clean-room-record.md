# Clean-room Record

This repository is designed for public inspection from its first commit.

- Problem domain: public model deployment artifact validation.
- Inputs: public model specifications, public datasets, and generated fixtures.
- Implementation: independently designed vocabulary, manifest, report schema, and
  test suite.
- Excluded: employer code, schemas, configuration, model files, logs, tickets,
  screenshots, private URLs, credentials, internal terminology, and private metrics.
- Evidence: all benchmarks and compatibility claims must be generated in this
  repository.

Before any public remote, release, or case study, run the catalog public-repository
gate against the complete Git history and staged tree.
