# Product phases

The repository has one locally accepted baseline and one selected planning increment:

- [Phase 1 - Model Release Gate](phase-1-model-release-gate/README.md)
- [Phase 2 - Model Lifecycle Experiment](phase-2-model-lifecycle/README.md): planning;
  no lifecycle implementation or measured results yet.

Do not pre-create future phases. Unfinished Phase 1 requirements, maintenance,
defects, and compatibility corrections remain Phase 1 work. A new phase requires
a newly evidenced capability or failure boundary, a product-owned problem, a
requirement change, and independent acceptance.
